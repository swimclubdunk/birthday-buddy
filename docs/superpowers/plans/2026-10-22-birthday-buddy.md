# Birthday Buddy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tiny Windows tray app that stores names + birthdates and shows a Windows notification on each birthday and a configurable heads-up beforehand, shipped as one self-contained `.exe`.

**Architecture:** One WinForms project (.NET 10). Pure logic (`BirthdayCalendar`, `PersonRules`, `ReminderPlanner`, `Wording`) is free of I/O and fully unit-tested; thin adapters (`BirthdayStore`, `Library`, `StartupRegistration`, `SingleInstance`, `ReminderService`) handle files, registry, OS events; the UI (`TrayApp`, `MainWindow`, `PeopleList`, `PersonEditor`) sits on top. Everything user-facing is worded in `Wording`.

**Tech Stack:** C# / .NET 10 (`net10.0-windows`), Windows Forms, System.Text.Json, xUnit (tests only).

**Spec:** `docs/superpowers/specs/2026-10-22-birthday-buddy-design.md`

## Global Constraints

- Target `net10.0-windows`, `UseWindowsForms`, nullable enabled. No third-party runtime packages (test-only packages from the xUnit template are fine).
- Data directory `%AppData%\BirthdayBuddy`; data file `birthdays.json`; log file `log.txt`.
- Heads-up days: 0–30 (0 = heads-ups off), default 3. Start with Windows: default on.
- Names trimmed, required, ≤ 60 chars. Year optional, 1900…current year, full date not in the future. 29 Feb always allowed for day/month.
- Feb 29 birthdays occur on 28 Feb in non-leap years.
- Startup entry: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, value name `BirthdayBuddy`, data `"<exe path>" --tray`.
- No modal dialogs for input errors; validation is inline.
- Balloon limits: title ≤ 63 chars, body ≤ 255 chars; tray tooltip ≤ 127 chars.
- Publish: `win-x64`, self-contained, `PublishSingleFile`, `EnableCompressionInSingleFile`, `IncludeNativeLibrariesForSelfExtract`, output `dist/BirthdayBuddy.exe`.
- Every commit message ends with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (pass it as a second `-m`).

## Review Focus

1. A hand-edited or damaged-but-valid `birthdays.json` (31 Feb, blank name, `headsUpDays: 999`, `"people": null`) must load without crashing: invalid people dropped, settings clamped. → test in Task 6.
2. Many reminders in one check (e.g. widening heads-up to 30 days on a big list) must produce one notification within the 63/255 limits, ending "…and N more." → test in Task 5.
3. Several long names with a birthday today must not overflow the 127-char tray tooltip (`NotifyIcon.Text` throws above that). → test in Task 5.
4. An exe living in a folder with spaces (`C:\Users\Jo Smith\Downloads`) must still start at login: the Run value is quoted. → test in Task 8.
5. Changing the heads-up window after a heads-up was already sent must not send it again. → test in Task 4.

```csharp
namespace BirthdayBuddy.Core;

/// <summary>Pure date math for birthdays. No clock, no I/O.</summary>
public static class BirthdayCalendar
{
    /// <summary>The person's birthday in <paramref name="year"/>; 29 Feb becomes 28 Feb in non-leap years.</summary>
    public static DateOnly OccurrenceIn(Person person, int year)
    {
        int day = person.Month == 2 && person.Day == 29 && !DateTime.IsLeapYear(year) ? 28 : person.Day;
        return new DateOnly(year, person.Month, day);
    }

    public static DateOnly NextOccurrence(Person person, DateOnly today)
    {
        var thisYear = OccurrenceIn(person, today.Year);
        return thisYear >= today ? thisYear : OccurrenceIn(person, today.Year + 1);
    }

    public static int DaysUntil(Person person, DateOnly today) =>
        NextOccurrence(person, today).DayNumber - today.DayNumber;

    public static int? AgeOn(Person person, DateOnly occurrence) =>
        person.Year is int year ? occurrence.Year - year : null;

    public static IReadOnlyList<Person> Upcoming(IEnumerable<Person> people, DateOnly today) =>
        people.OrderBy(p => DaysUntil(p, today))
              .ThenBy(p => p.Name, StringComparer.CurrentCultureIgnoreCase)
              .ToList();

    /// <summary>True if the day exists in the month in at least one year (so 29 Feb is valid).</summary>
    public static bool IsValidDate(int day, int month) =>
        month is >= 1 and <= 12 && day >= 1 && day <= DateTime.DaysInMonth(2000, month);
}
```

```csharp
using System.Globalization;

namespace BirthdayBuddy.Core;

public static class PersonRules
{
    public const int MaxNameLength = 60;
    public const int MinYear = 1900;

    /// <summary>Returns a friendly error message, or null when the input is valid.</summary>
    public static string? Validate(string name, int day, int month, int? year, DateOnly today)
    {
        var trimmed = name.Trim();
        if (trimmed.Length == 0) return "Please enter a name.";
        if (trimmed.Length > MaxNameLength) return $"Names can be up to {MaxNameLength} characters.";
        if (!BirthdayCalendar.IsValidDate(day, month)) return "That date doesn't exist.";

        if (year is int y)
        {
            if (y < MinYear || y > today.Year) return $"Year must be between {MinYear} and {today.Year}.";
            if (month == 2 && day == 29 && !DateTime.IsLeapYear(y)) return $"{y} wasn't a leap year.";
            if (new DateOnly(y, month, day) > today) return "That date is in the future.";
        }

        return null;
    }

    /// <summary>Blank means "no year". Returns false for anything that isn't a whole number.</summary>
    public static bool TryParseYear(string text, out int? year)
    {
        year = null;
        if (string.IsNullOrWhiteSpace(text)) return true;
        if (!int.TryParse(text.Trim(), NumberStyles.None, CultureInfo.InvariantCulture, out int parsed)) return false;
        year = parsed;
        return true;
    }

    public static Person Create(string name, int day, int month, int? year) =>
        new() { Name = name.Trim(), Day = day, Month = month, Year = year };

    /// <summary>Applies an edit. Changing the day or month clears the sent-reminder markers.</summary>
    public static Person Edit(Person original, string name, int day, int month, int? year)
    {
        bool dateChanged = original.Day != day || original.Month != month;
        return original with
        {
            Name = name.Trim(),
            Day = day,
            Month = month,
            Year = year,
            LastHeadsUp = dateChanged ? null : original.LastHeadsUp,
            LastBirthdayNotice = dateChanged ? null : original.LastBirthdayNotice,
        };
    }
}
```

```csharp
namespace BirthdayBuddy.Core;

/// <summary>Decides which reminders are due right now. Pure: same input, same output.</summary>
public static class ReminderPlanner
{
    public static ReminderPlan Plan(IReadOnlyList<Person> people, Settings settings, DateOnly today)
    {
        int window = Math.Clamp(settings.HeadsUpDays, 0, Settings.MaxHeadsUpDays);
        var reminders = new List<Reminder>();
        var updated = new List<Person>(people.Count);

        foreach (var person in people)
        {
            var next = BirthdayCalendar.NextOccurrence(person, today);
            int days = next.DayNumber - today.DayNumber;
            var result = person;

            if (days == 0)
            {
                if (person.LastBirthdayNotice != today)
                {
                    reminders.Add(new Reminder(ReminderKind.Birthday, person.Name, next, 0, BirthdayCalendar.AgeOn(person, next)));
                    result = person with { LastBirthdayNotice = today };
                }
            }
            else if (days <= window && person.LastHeadsUp != next)
            {
                reminders.Add(new Reminder(ReminderKind.HeadsUp, person.Name, next, days, BirthdayCalendar.AgeOn(person, next)));
                result = person with { LastHeadsUp = next };
            }

            updated.Add(result);
        }

        var ordered = reminders
            .OrderBy(r => r.Kind == ReminderKind.Birthday ? 0 : 1)
            .ThenBy(r => r.DaysUntil)
            .ThenBy(r => r.Name, StringComparer.CurrentCultureIgnoreCase)
            .ToList();

        return new ReminderPlan(ordered, updated);
    }
}
```

```csharp
using System.Globalization;

namespace BirthdayBuddy.Core;

/// <summary>Every user-facing sentence lives here, so wording stays consistent and testable.</summary>
public static class Wording
{
    public const int MaxTitle = 63;     // NotifyIcon balloon title limit
    public const int MaxBody = 255;     // NotifyIcon balloon text limit
    public const int MaxTooltip = 127;  // NotifyIcon.Text limit
    const int MaxLines = 4;

    public static (string Title, string Body) Notification(IReadOnlyList<Reminder> reminders, CultureInfo culture)
    {
        if (reminders.Count == 0) throw new ArgumentException("Nothing to notify about.", nameof(reminders));

        int birthdays = reminders.Count(r => r.Kind == ReminderKind.Birthday);
        int headsUps = reminders.Count - birthdays;
        string title = birthdays switch
        {
            0 => headsUps == 1 ? "Upcoming birthday" : $"{headsUps} upcoming birthdays",
            1 => "🎂 Birthday today",
            _ => $"🎂 {birthdays} birthdays today",
        };

        var lines = reminders.Select(r => Line(r, culture)).ToList();
        if (lines.Count > MaxLines)
            lines = [.. lines.Take(MaxLines - 1), $"…and {reminders.Count - (MaxLines - 1)} more."];

        int perLine = (MaxBody - (lines.Count - 1)) / lines.Count;
        return (title, string.Join("\n", lines.Select(l => Truncate(l, perLine))));
    }

    public static string Line(Reminder r, CultureInfo culture) => r.Kind == ReminderKind.Birthday
        ? (r.Age is int age ? $"It's {r.Name}'s birthday today! Turning {age}." : $"It's {r.Name}'s birthday today!")
        : $"{r.Name}'s birthday is {When(r.DaysUntil)} ({r.Date.ToString("ddd d MMM", culture)}).";

    public static string Status(int daysUntil) => daysUntil switch
    {
        0 => "Today 🎉",
        1 => "Tomorrow",
        _ => $"in {daysUntil} days",
    };

    public static string Detail(DateOnly occurrence, int? age, CultureInfo culture)
    {
        var date = occurrence.ToString("d MMM", culture);
        return age is int a ? $"{date} · turns {a}" : date;
    }

    public static string UpcomingLine(Person person, int daysUntil) => $"{person.Name} · {Status(daysUntil)}";

    /// <param name="upcoming">People already sorted by <see cref="BirthdayCalendar.Upcoming"/>.</param>
    public static string Subtitle(IReadOnlyList<Person> upcoming, DateOnly today)
    {
        if (upcoming.Count == 0) return "No birthdays yet";

        var todays = upcoming.Where(p => BirthdayCalendar.DaysUntil(p, today) == 0).Select(p => p.Name).ToList();
        if (todays.Count > 0) return $"🎉 Today: {string.Join(", ", todays)}";

        var next = upcoming[0];
        return $"Next up: {next.Name}, {When(BirthdayCalendar.DaysUntil(next, today))}";
    }

    public static string Tooltip(IEnumerable<string> namesWithBirthdayToday)
    {
        var names = namesWithBirthdayToday.ToList();
        var text = names.Count switch
        {
            0 => "Birthday Buddy",
            1 => $"🎂 {names[0]}'s birthday today",
            _ => $"🎂 Birthdays today: {string.Join(", ", names)}",
        };
        return Truncate(text, MaxTooltip);
    }

    static string When(int days) => days == 1 ? "tomorrow" : $"in {days} days";

    static string Truncate(string text, int max) => text.Length <= max ? text : text[..(max - 1)] + "…";
}
```

```csharp
/// <summary>Append-only error log. Never throws: logging must not take the app down.</summary>
public static class Log
{
    const long MaxBytes = 1_000_000;

    public static string? FilePath { get; set; }

    public static void Error(string message, Exception? ex = null)
    {
        if (FilePath is null) return;
        try
        {
            Directory.CreateDirectory(Path.GetDirectoryName(FilePath)!);
            var info = new FileInfo(FilePath);
            if (info.Exists && info.Length > MaxBytes) File.Move(FilePath, FilePath + ".old", overwrite: true);

            var detail = ex is null ? "" : Environment.NewLine + ex;
            File.AppendAllText(FilePath, $"{DateTime.Now:yyyy-MM-dd HH:mm:ss}  {message}{detail}{Environment.NewLine}");
        }
        catch
        {
            // Nowhere left to report this.
        }
    }
}
```

```csharp
using System.Text.Json;

namespace BirthdayBuddy.Core;

/// <param name="RecoveredFrom">Where the unreadable file was moved to, or null if it loaded fine.</param>
public sealed record LoadResult(AppData Data, string? RecoveredFrom);

/// <summary>Reads and writes birthdays.json. Saves are atomic; unreadable files are kept aside, never lost.</summary>
public sealed class BirthdayStore(string directoryPath)
{
    static readonly JsonSerializerOptions Json = new(JsonSerializerDefaults.Web) { WriteIndented = true };

    public static string DefaultDirectory =>
        Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData), "BirthdayBuddy");

    public string DirectoryPath { get; } = directoryPath;
    public string FilePath { get; } = Path.Combine(directoryPath, "birthdays.json");

    public LoadResult Load()
    {
        if (!File.Exists(FilePath)) return new LoadResult(new AppData(), null);

        try
        {
            var data = JsonSerializer.Deserialize<AppData>(File.ReadAllText(FilePath), Json)
                       ?? throw new JsonException("The file was empty.");
            return new LoadResult(Sanitize(data), null);
        }
        catch (Exception ex) when (ex is JsonException or NotSupportedException or IOException or UnauthorizedAccessException)
        {
            Log.Error("Could not read birthdays.json; starting fresh.", ex);
            var backup = Path.Combine(DirectoryPath, $"birthdays.corrupt-{DateTime.Now:yyyyMMdd-HHmmss}.json");
            File.Move(FilePath, backup, overwrite: true);
            return new LoadResult(new AppData(), backup);
        }
    }

    public void Save(AppData data)
    {
```

```csharp
namespace BirthdayBuddy.Core;

/// <summary>The live birthday library: in-memory data, saved on every change.</summary>
public sealed class Library(BirthdayStore store, AppData data)
{
    public AppData Data { get; private set; } = data;

    /// <summary>Raised when people or settings change (not when reminder markers are recorded).</summary>
    public event EventHandler? Changed;

    public void Upsert(Person person) =>
        Commit(Data with { People = Data.People.Where(p => p.Id != person.Id).Append(person).ToList() }, notify: true);

    public void Remove(Guid id) =>
        Commit(Data with { People = Data.People.Where(p => p.Id != id).ToList() }, notify: true);

    public void UpdateSettings(Settings settings) =>
        Commit(Data with { Settings = settings }, notify: true);

    /// <summary>Saves sent-reminder markers. Doesn't raise Changed: a check must not trigger another check.</summary>
    public void RecordSent(IReadOnlyList<Person> people) =>
        Commit(Data with { People = people }, notify: false);

    void Commit(AppData next, bool notify)
    {
        Data = next;
        try
        {
            store.Save(next);
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            Log.Error("Could not save birthdays.json.", ex);
        }
        if (notify) Changed?.Invoke(this, EventArgs.Empty);
    }
}
```

```csharp
using Microsoft.Win32;

namespace BirthdayBuddy.Core;

/// <summary>Per-user "start at login" entry in the HKCU Run key. No admin rights needed.</summary>
public sealed class StartupRegistration
{
    public const string DefaultRunKeyPath = @"Software\Microsoft\Windows\CurrentVersion\Run";

    readonly string _runKeyPath;
    readonly string _valueName;

    public StartupRegistration() : this(DefaultRunKeyPath, "BirthdayBuddy") { }

    public StartupRegistration(string runKeyPath, string valueName)
    {
        _runKeyPath = runKeyPath;
        _valueName = valueName;
    }

    public static string CommandFor(string exePath) => $"\"{exePath}\" --tray";

    public string? RegisteredCommand()
    {
        using var key = Registry.CurrentUser.OpenSubKey(_runKeyPath);
        return key?.GetValue(_valueName) as string;
    }

    /// <summary>Adds the entry, or points it at <paramref name="exePath"/> if the exe moved.</summary>
    public void Register(string exePath)
    {
        var command = CommandFor(exePath);
        using var key = Registry.CurrentUser.CreateSubKey(_runKeyPath);
        if (key.GetValue(_valueName) as string != command) key.SetValue(_valueName, command);
    }

    public void Unregister()
    {
        using var key = Registry.CurrentUser.OpenSubKey(_runKeyPath, writable: true);
        key?.DeleteValue(_valueName, throwOnMissingValue: false);
    }
}
```

```csharp
using System.Runtime.InteropServices;

namespace BirthdayBuddy.Core;

/// <summary>Keeps one copy running per user session; later launches ask it to show its window.</summary>
public sealed class SingleInstance : IDisposable
{
    const string DefaultMutexName = @"Local\BirthdayBuddy.Instance";
    const string DefaultEventName = @"Local\BirthdayBuddy.Show";

    readonly Mutex _mutex;
    readonly EventWaitHandle _showRequested;
    RegisteredWaitHandle? _wait;

    SingleInstance(Mutex mutex, EventWaitHandle showRequested)
    {
        _mutex = mutex;
        _showRequested = showRequested;
    }

    /// <summary>Returns null when another instance already holds the mutex.</summary>
    public static SingleInstance? TryAcquire(string mutexName = DefaultMutexName, string eventName = DefaultEventName)
    {
        var mutex = new Mutex(initiallyOwned: false, mutexName, out bool createdNew);
        if (!createdNew)
        {
            mutex.Dispose();
            return null;
        }
        return new SingleInstance(mutex, new EventWaitHandle(false, EventResetMode.AutoReset, eventName));
    }

    /// <summary>Asks the running instance to show itself, letting it take the foreground.</summary>
    public static void SignalExisting(string eventName = DefaultEventName)
    {
        if (!EventWaitHandle.TryOpenExisting(eventName, out var handle)) return;
        using (handle)
        {
            AllowSetForegroundWindow(AsfwAny);
            handle.Set();
        }
    }

    /// <summary>Runs <paramref name="callback"/> on <paramref name="context"/> each time another launch signals.</summary>
    public void OnActivationRequested(Action callback, SynchronizationContext context)
    {
        _wait?.Unregister(null);
        _wait = ThreadPool.RegisterWaitForSingleObject(
            _showRequested, (_, _) => context.Post(_ => callback(), null), null, Timeout.Infinite, executeOnlyOnce: false);
    }

    public void Dispose()
    {
        _wait?.Unregister(null);
        _showRequested.Dispose();
        _mutex.Dispose();
    }

    const int AsfwAny = -1;

    [DllImport("user32.dll")]
    static extern bool AllowSetForegroundWindow(int processId);
}
```

```csharp
using Microsoft.Win32;

namespace BirthdayBuddy.Core;

/// <summary>
/// Decides when to check for reminders: at start, just after local midnight (re-checked at least hourly),
/// on wake from sleep, on clock/time-zone changes, and whenever the library changes.
/// </summary>
public sealed class ReminderService(Library library, Action<IReadOnlyList<Reminder>> notify, TimeProvider time) : IDisposable
{
    static readonly TimeSpan MaxWait = TimeSpan.FromHours(1);

    System.Windows.Forms.Timer? _timer;
    SynchronizationContext? _ui;

    public DateOnly Today => DateOnly.FromDateTime(time.GetLocalNow().DateTime);

    /// <summary>Raised on the UI thread after each scheduled check.</summary>
    public event EventHandler? Checked;

    /// <summary>Call on the UI thread once the app is ready.</summary>
    public void Start()
    {
        _ui = SynchronizationContext.Current ?? throw new InvalidOperationException("Start must run on the UI thread.");
        _timer = new System.Windows.Forms.Timer();
        _timer.Tick += (_, _) => Run();
        SystemEvents.PowerModeChanged += OnPowerModeChanged;
        SystemEvents.TimeChanged += OnTimeChanged;
        library.Changed += OnLibraryChanged;
        Run();
    }

    public IReadOnlyList<Reminder> CheckNow()
    {
        var plan = ReminderPlanner.Plan(library.Data.People, library.Data.Settings, Today);
        if (plan.Reminders.Count > 0)
        {
            library.RecordSent(plan.UpdatedPeople);
            notify(plan.Reminders);
        }
        return plan.Reminders;
    }

    public static TimeSpan NextCheckDelay(DateTimeOffset localNow)
    {
        var untilMidnight = localNow.Date.AddDays(1).AddSeconds(5) - localNow.DateTime;
        return untilMidnight < MaxWait ? untilMidnight : MaxWait;
    }

    void Run()
    {
        try
        {
            CheckNow();
        }
        catch (Exception ex)
        {
            Log.Error("Reminder check failed.", ex);
        }

        if (_timer is not null)
        {
            _timer.Stop();
            _timer.Interval = Math.Max(1000, (int)NextCheckDelay(time.GetLocalNow()).TotalMilliseconds);
            _timer.Start();
        }

        Checked?.Invoke(this, EventArgs.Empty);
    }

    // SystemEvents fire on their own thread; hop back to the UI thread.
    void OnPowerModeChanged(object? sender, PowerModeChangedEventArgs e)
    {
        if (e.Mode == PowerModes.Resume) _ui?.Post(_ => Run(), null);
    }

    void OnTimeChanged(object? sender, EventArgs e) => _ui?.Post(_ =>
    {
        TimeZoneInfo.ClearCachedData();
        Run();
    }, null);

    void OnLibraryChanged(object? sender, EventArgs e) => Run();

    public void Dispose()
    {
        SystemEvents.PowerModeChanged -= OnPowerModeChanged;
        SystemEvents.TimeChanged -= OnTimeChanged;
        library.Changed -= OnLibraryChanged;
        _timer?.Dispose();
    }
}
```

```csharp
using System.Text;

namespace BirthdayBuddy.Ui;

/// <summary>Writes square 32bpp bitmaps into a multi-size .ico (classic DIB entries with alpha).</summary>
public static class IcoWriter
{
    public static void Write(Stream output, IReadOnlyList<Bitmap> images)
    {
        var payloads = images.Select(Dib).ToList();
        using var w = new BinaryWriter(output, Encoding.UTF8, leaveOpen: true);

        w.Write((ushort)0);              // reserved
        w.Write((ushort)1);              // type: icon
        w.Write((ushort)images.Count);

        int offset = 6 + 16 * images.Count;
        for (int i = 0; i < images.Count; i++)
        {
            int size = images[i].Width;
            w.Write((byte)(size >= 256 ? 0 : size));
            w.Write((byte)(size >= 256 ? 0 : size));
            w.Write((byte)0);            // palette colours
            w.Write((byte)0);            // reserved
            w.Write((ushort)1);          // planes
            w.Write((ushort)32);         // bits per pixel
            w.Write(payloads[i].Length);
            w.Write(offset);
            offset += payloads[i].Length;
        }

        foreach (var payload in payloads) w.Write(payload);
    }

    static byte[] Dib(Bitmap bmp)
    {
        int size = bmp.Width;
        int maskStride = (size + 31) / 32 * 4;
        using var ms = new MemoryStream();
        using var w = new BinaryWriter(ms);

        w.Write(40);                     // BITMAPINFOHEADER size
        w.Write(size);
        w.Write(size * 2);               // XOR + AND masks
        w.Write((ushort)1);
        w.Write((ushort)32);
        w.Write(0);                      // BI_RGB
        w.Write(size * size * 4 + maskStride * size);
        w.Write(0); w.Write(0); w.Write(0); w.Write(0);

        for (int y = size - 1; y >= 0; y--)      // bottom-up BGRA
        for (int x = 0; x < size; x++)
        {
            var c = bmp.GetPixel(x, y);
            w.Write(c.B); w.Write(c.G); w.Write(c.R); w.Write(c.A);
        }

        w.Write(new byte[maskStride * size]);    // AND mask unused: alpha carries transparency
        return ms.ToArray();
    }
}
```

```csharp
namespace BirthdayBuddy.Ui;

/// <summary>How a control is coloured by <see cref="Widgets.ApplyPalette"/>; stored in Control.Tag.</summary>
public enum Role { Default, Subtle, Error, Accent, Border, PrimaryButton, SecondaryButton, DangerButton }

public static class Widgets
{
    public static Button Button(string text, Role role = Role.SecondaryButton) => new()
    {
        Text = text,
        Tag = role,
        AutoSize = true,
        FlatStyle = FlatStyle.Flat,
        Font = Theme.Body,
        Padding = new Padding(10, 2, 10, 2),
        Cursor = Cursors.Hand,
        UseVisualStyleBackColor = false,
    };

    public static Label Label(string text = "", Role role = Role.Default, Font? font = null) => new()
    {
        Text = text,
        Tag = role,
        AutoSize = true,
        Font = font ?? Theme.Body,
        UseMnemonic = false,
    };

    /// <summary>Colours <paramref name="root"/> and its children by type and <see cref="Role"/>.</summary>
    public static void ApplyPalette(Control root, Palette p)
    {
        var role = root.Tag as Role? ?? Role.Default;
        switch (root)
        {
            case Button button:
                StyleButton(button, role, p);
                break;
            case PeopleList list:
                list.ApplyPalette(p);
                break;
            case TextBox or ComboBox or NumericUpDown:
                root.BackColor = p.Surface;
                root.ForeColor = p.Text;
                return; // don't recurse into their internal parts
            default:
                root.BackColor = role == Role.Border ? p.Border : p.Window;
                root.ForeColor = role switch
                {
                    Role.Subtle => p.SubtleText,
                    Role.Error => p.Danger,
                    Role.Accent => p.Accent,
                    _ => p.Text,
                };
                break;
        }

        foreach (Control child in root.Controls) ApplyPalette(child, p);
    }

    static void StyleButton(Button b, Role role, Palette p)
    {
        b.FlatAppearance.BorderSize = role == Role.SecondaryButton ? 1 : 0;
        b.FlatAppearance.BorderColor = p.Border;
        (b.BackColor, b.ForeColor) = role switch
        {
            Role.PrimaryButton => (p.Accent, p.AccentText),
            Role.DangerButton => (p.Window, p.Danger),
            _ => (p.Surface, p.Text),
        };
        b.FlatAppearance.MouseOverBackColor = role == Role.PrimaryButton ? ControlPaint.Light(p.Accent, 0.25f) : p.SurfaceHover;
        b.FlatAppearance.MouseDownBackColor = b.FlatAppearance.MouseOverBackColor;
    }
}
```

```csharp
using System.Drawing.Drawing2D;
using System.Globalization;
using BirthdayBuddy.Core;

namespace BirthdayBuddy.Ui;

/// <summary>Owner-drawn list of soft cards: name and date on the left, status on the right.</summary>
public sealed class PeopleList : ListBox
{
    const int RowHeight = 62;
    const TextFormatFlags TextFlags = TextFormatFlags.NoPrefix | TextFormatFlags.SingleLine | TextFormatFlags.EndEllipsis;

    Palette _palette = Theme.Light;
    DateOnly _today = DateOnly.FromDateTime(DateTime.Today);
    int _hover = -1;

    public event EventHandler<Person>? PersonActivated;

    public PeopleList()
    {
        DrawMode = DrawMode.OwnerDrawFixed;
        BorderStyle = BorderStyle.None;
        IntegralHeight = false;
        Cursor = Cursors.Hand;
        ItemHeight = RowHeight;
    }

    public void ApplyPalette(Palette palette)
    {
        _palette = palette;
        BackColor = palette.Window;
        Invalidate();
    }

    public void SetPeople(IReadOnlyList<Person> sorted, DateOnly today)
    {
        _today = today;
        _hover = -1;
        BeginUpdate();
        Items.Clear();
        foreach (var person in sorted) Items.Add(person);
        EndUpdate();
    }

    protected override void OnHandleCreated(EventArgs e)
    {
        base.OnHandleCreated(e);
        ItemHeight = LogicalToDeviceUnits(RowHeight);
    }

    protected override void OnDpiChangedAfterParent(EventArgs e)
    {
        base.OnDpiChangedAfterParent(e);
        ItemHeight = LogicalToDeviceUnits(RowHeight);
    }

    protected override void OnDrawItem(DrawItemEventArgs e)
    {
        var g = e.Graphics;
        using (var background = new SolidBrush(_palette.Window)) g.FillRectangle(background, e.Bounds);
        if (e.Index < 0 || e.Index >= Items.Count || Items[e.Index] is not Person person) return;

        g.SmoothingMode = SmoothingMode.AntiAlias;
        int gap = LogicalToDeviceUnits(4), side = LogicalToDeviceUnits(16), pad = LogicalToDeviceUnits(14);
        var card = new Rectangle(e.Bounds.X + side, e.Bounds.Y + gap, e.Bounds.Width - 2 * side - 1, e.Bounds.Height - 2 * gap);
        bool highlighted = e.Index == _hover || (Focused && (e.State & DrawItemState.Selected) != 0);

        using (var path = Shapes.RoundedRect(card, LogicalToDeviceUnits(10)))
        using (var fill = new SolidBrush(highlighted ? _palette.SurfaceHover : _palette.Surface))
        using (var pen = new Pen(_palette.Border))
        {
            g.FillPath(fill, path);
            g.DrawPath(pen, path);
        }

        var next = BirthdayCalendar.NextOccurrence(person, _today);
        int days = next.DayNumber - _today.DayNumber;
        string status = Wording.Status(days);
        var statusFont = days == 0 ? Theme.BodyBold : Theme.Small;
        var statusColor = days == 0 ? _palette.Accent : _palette.SubtleText;
        int statusWidth = TextRenderer.MeasureText(g, status, statusFont).Width;

        int textWidth = card.Width - 3 * pad - statusWidth;
        int half = card.Height / 2;
        var nameRect = new Rectangle(card.X + pad, card.Y, textWidth, half + LogicalToDeviceUnits(2));
        var detailRect = new Rectangle(card.X + pad, card.Y + half + LogicalToDeviceUnits(1), textWidth, half);
        var statusRect = new Rectangle(card.Right - pad - statusWidth, card.Y, statusWidth, card.Height);
        string detail = Wording.Detail(next, BirthdayCalendar.AgeOn(person, next), CultureInfo.CurrentCulture);

        TextRenderer.DrawText(g, person.Name, Theme.BodyBold, nameRect, _palette.Text, TextFlags | TextFormatFlags.Bottom);
        TextRenderer.DrawText(g, detail, Theme.Small, detailRect, _palette.SubtleText, TextFlags | TextFormatFlags.Top);
        TextRenderer.DrawText(g, status, statusFont, statusRect, statusColor, TextFlags | TextFormatFlags.VerticalCenter | TextFormatFlags.Right);
    }

    protected override void OnMouseMove(MouseEventArgs e)
    {
        base.OnMouseMove(e);
        SetHover(ItemAt(e.Location));
    }

    protected override void OnMouseLeave(EventArgs e)
    {
        base.OnMouseLeave(e);
        SetHover(-1);
    }

    protected override void OnMouseClick(MouseEventArgs e)
    {
        base.OnMouseClick(e);
        int index = ItemAt(e.Location);
        if (e.Button == MouseButtons.Left && index >= 0 && Items[index] is Person person) PersonActivated?.Invoke(this, person);
    }

    protected override void OnKeyDown(KeyEventArgs e)
    {
        base.OnKeyDown(e);
        if (e.KeyCode == Keys.Enter && SelectedItem is Person person)
        {
            PersonActivated?.Invoke(this, person);
            e.Handled = true;
        }
    }

    int ItemAt(Point point)
    {
        int index = IndexFromPoint(point);
        return index >= 0 && index < Items.Count && GetItemRectangle(index).Contains(point) ? index : -1;
    }

    void SetHover(int index)
    {
        if (index == _hover) return;
        if (_hover >= 0 && _hover < Items.Count) Invalidate(GetItemRectangle(_hover));
        _hover = index;
        if (_hover >= 0 && _hover < Items.Count) Invalidate(GetItemRectangle(_hover));
    }
```

```csharp
    {
```

```csharp
        if (WindowState == FormWindowState.Minimized) WindowState = FormWindowState.Normal;
        Activate();
    }

    void ShowEditor(Person? person)
    {
        _list.Visible = false;
        _empty.Visible = false;
        _add.Visible = false;
        _editor.Visible = true;
        if (person is null) _editor.BeginAdd();
        else _editor.BeginEdit(person);
    }

    void RefreshContent()
    {
        var today = _today();
        var people = BirthdayCalendar.Upcoming(_library.Data.People, today);
        _list.SetPeople(people, today);
        _subtitle.Text = Wording.Subtitle(people, today);

        if (!_editor.Visible)
        {
            _list.Visible = people.Count > 0;
            _empty.Visible = people.Count == 0;
        }
        _add.Visible = !_editor.Visible && people.Count > 0; // the empty state has its own button

        _syncing = true;
        _headsUp.Value = Math.Clamp(_library.Data.Settings.HeadsUpDays, 0, Settings.MaxHeadsUpDays);
        _startup.Checked = _library.Data.Settings.StartWithWindows;
        _syncing = false;
    }

    void OnStartupToggled()
    {
        if (_syncing) return;
        bool wanted = _startup.Checked;
        if (_setStartWithWindows(wanted))
        {
            _note.Text = "";
            return;
        }
        _syncing = true;
        _startup.Checked = !wanted;
        _syncing = false;
        _note.Text = "Couldn't change the startup setting. Details are in log.txt.";
    }

    void OnLibraryChanged(object? sender, EventArgs e)
    {
        if (Visible) RefreshContent();
    }

    protected override void OnVisibleChanged(EventArgs e)
    {
        base.OnVisibleChanged(e);
        if (!Visible) return;
        bool dark = Theme.IsDarkMode();
        Widgets.ApplyPalette(this, dark ? Theme.Dark : Theme.Light);
        Theme.ApplyTitleBar(this, dark);
        RefreshContent();
    }

    protected override void OnFormClosing(FormClosingEventArgs e)
    {
        if (e.CloseReason == CloseReason.UserClosing)
        {
            e.Cancel = true;
            _editor.Visible = false;
            Hide();
        }
        base.OnFormClosing(e);
    }

    protected override bool ProcessCmdKey(ref Message msg, Keys keyData)
    {
        if (keyData == Keys.Escape && !_editor.Visible)
        {
            Hide();
            return true;
        }
        return base.ProcessCmdKey(ref msg, keyData);
    }

    protected override void Dispose(bool disposing)
    {
        if (disposing) _library.Changed -= OnLibraryChanged;
        base.Dispose(disposing);
    }
}
```

```csharp
using BirthdayBuddy.Core;

namespace BirthdayBuddy.Ui;

/// <summary>The app's lifetime: tray icon, menu, reminders, and the (lazily created) window.</summary>
public sealed class TrayApp : ApplicationContext
{
    readonly Library _library;
    readonly NotifyIcon _tray;
    readonly ContextMenuStrip _menu = new();
    readonly Font _boldMenuFont;
    readonly Notifier _notifier;
    readonly ReminderService _reminders;
    readonly StartupRegistration _startup = new();
    MainWindow? _window;

    static string ExePath => Environment.ProcessPath ?? Application.ExecutablePath;

    public TrayApp(bool startInTray, SingleInstance instance)
    {
        var store = new BirthdayStore(BirthdayStore.DefaultDirectory);
        var loaded = store.Load();
        _library = new Library(store, loaded.Data);

        _boldMenuFont = new Font(_menu.Font, FontStyle.Bold);
        _menu.Opening += (_, e) =>
        {
            BuildMenu();
            e.Cancel = false;
        };

        _tray = new NotifyIcon
        {
            Icon = AppIcon.Load(SystemInformation.SmallIconSize),
            Text = "Birthday Buddy",
            ContextMenuStrip = _menu,
            Visible = true,
        };
        _tray.MouseClick += (_, e) =>
        {
            if (e.Button == MouseButtons.Left) ShowWindow();
        };

        _notifier = new Notifier(_tray);
        _notifier.Clicked += (_, _) => ShowWindow();

        RefreshStartupEntry();

        _reminders = new ReminderService(_library, _notifier.Show, TimeProvider.System);
        _reminders.Checked += (_, _) => RefreshTooltip();
        _library.Changed += (_, _) => RefreshTooltip();
        instance.OnActivationRequested(ShowWindow, SynchronizationContext.Current!);
        BuildMenu();
        _reminders.Start();

        if (loaded.RecoveredFrom is not null)
            _notifier.ShowMessage("Birthday Buddy",
                $"Your birthday list couldn't be read, so a fresh one was started. The old file was kept as {Path.GetFileName(loaded.RecoveredFrom)}.");

        if (!startInTray) ShowWindow();
    }

    /// <summary>Turns start-at-login on or off. Returns false (and logs) if the registry refused.</summary>
    public bool TrySetStartWithWindows(bool enabled)
    {
        try
        {
            if (enabled) _startup.Register(ExePath);
            else _startup.Unregister();
        }
        catch (Exception ex)
        {
            Log.Error("Could not change the startup entry.", ex);
            return false;
        }
        _library.UpdateSettings(_library.Data.Settings with { StartWithWindows = enabled });
        return true;
    }

    /// <summary>On every launch, keep the startup entry pointing at wherever this exe now lives.</summary>
    void RefreshStartupEntry()
    {
        if (!_library.Data.Settings.StartWithWindows) return;
        try
        {
            _startup.Register(ExePath);
        }
        catch (Exception ex)
        {
            Log.Error("Could not register the startup entry.", ex);
        }
    }

    void BuildMenu()
    {
        _menu.Items.Clear();
        _menu.Items.Add(new ToolStripMenuItem("Open Birthday Buddy", null, (_, _) => ShowWindow()) { Font = _boldMenuFont });
        _menu.Items.Add(new ToolStripSeparator());

        var today = _reminders.Today;
        var upcoming = BirthdayCalendar.Upcoming(_library.Data.People, today).Take(3).ToList();
        if (upcoming.Count == 0)
            _menu.Items.Add(new ToolStripMenuItem("No birthdays yet") { Enabled = false });
        foreach (var person in upcoming)
        {
            var text = Wording.UpcomingLine(person, BirthdayCalendar.DaysUntil(person, today)).Replace("&", "&&");
            _menu.Items.Add(new ToolStripMenuItem(text) { Enabled = false });
        }

        _menu.Items.Add(new ToolStripSeparator());
        var startup = new ToolStripMenuItem("Start with Windows") { Checked = _library.Data.Settings.StartWithWindows };
        startup.Click += (_, _) =>
        {
            if (!TrySetStartWithWindows(!startup.Checked))
                _notifier.ShowMessage("Birthday Buddy", "Couldn't change the startup setting. Details are in log.txt.");
        };
        _menu.Items.Add(startup);
        _menu.Items.Add(new ToolStripSeparator());
        _menu.Items.Add(new ToolStripMenuItem("Exit", null, (_, _) => ExitThread()));
    }

    void RefreshTooltip()
    {
        var today = _reminders.Today;
        var names = _library.Data.People.Where(p => BirthdayCalendar.DaysUntil(p, today) == 0).Select(p => p.Name);
        _tray.Text = Wording.Tooltip(names);
    }

    void ShowWindow()
    {
        if (_window is null || _window.IsDisposed)
            _window = new MainWindow(_library, TrySetStartWithWindows, () => _reminders.Today);
        _window.ShowAndActivate();
    }

    protected override void ExitThreadCore()
    {
        _reminders.Dispose();
        _tray.Visible = false;
        _tray.Dispose();
        _window?.Dispose();
        _menu.Dispose();
        _boldMenuFont.Dispose();
        base.ExitThreadCore();
    }
}
```

Note: keep the constructor order: `_reminders` must be assigned before `BuildMenu()` and `_reminders.Start()` run, because both read `_reminders.Today`.

```markdown
# Birthday Buddy

A tiny Windows tray app that reminds you of birthdays.

- Add people with a name and birthday (year optional).
- Get a Windows notification on the day, plus a heads-up a few days before (you choose how many; 0 turns it off).
```
